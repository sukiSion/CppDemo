优先使用有作用域枚举（强类型枚举或枚举类0，而不是传统枚举）
# 通用规则
传统枚举缺陷：
1) 没有作用域
2) 会隐式转换为int
3) 会污染全局命名空间
4) 类型未知。只要求该类型足够大且能容纳下所有枚举项

传统枚举：
```cpp
enum color{
    red,
    blue,
    green
};
```
使用关键字class或struct，枚举就成了有作用域枚举
```cpp
enum class ColorScoped{
    red,
    blue,
    green
};
```
必须使用作用域运算符（::）来访问枚举项，不会隐式转换为int，也不会污染全局命名空间

1、优先使用枚举而不是宏
2、使用枚举表示相关联的具名常量的集合
3、优先使用enum class 而不是“普通”enum（参考scopedEnum.cpp）
4、不要对枚举项使用ALL_CAPS（全大写加下划线）命名方式（也适用于一般常量）
由于宏通常写成ALL_CAPS的方式，所以可能会与宏发生冲突
5、避免使用无名枚举
不是每个编译期常量都应该是enum。C++还允许将编译期常量定义为conseexpr变量。只有在相互关联的常量集合中使用enum
6、仅在必要时指定枚举的底层类型（默认情况下，有作用域enum的类型是int，因此可以前置声明enum）
7、仅在必要时指定枚举项的值
