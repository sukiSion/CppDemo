1、优先使用C++而不是C
原因：C++提供（比C）更好的类型检查和更多的写法支持。它为高级编程提供了更好的支持，并往往生成更快的代码
2、如果必须使用C，请使用C和C++的公共子集，并以C++的方式编译C代码

# 完整的源代码可用
由于C不是C++的子集，有些C程序使用C++编译器会出现问题
**在C++编译器中，'a'是char类型，为1字节，而在C编译器中，'a'为int类型，为4字节**

# 没有完整的源代码
1、使用C++编译器编译main函数
2、使用C++编译器链接程序
3、使用来自同一供应商的C和C++编译器，它们应该具有相同的调用约定

1、如果不是使用C作为接口，请在调用此类接口的代码里使用C++
与C相比，C++支持函数重载。这意味着可以定义名称相同但参数不同的函数。编译器带调用函数时选择正确的函数（参考functionOverloading.cpp）
C++编译器将参数类型和数目编码到函数名称中，这个过程被称为“名字重编”，并且每个C++编译器都可能有自己的特定方式，这一过程没有被标准化，也常常被称作“名字修饰”
可以使用extern "C" 链接说明符防止C++编译器重编这些名字。这样既可以从C++中调用C函数，也可以从C调用C++函数
extern "C"使用
```cpp
函数前：
extern "C" void foo(int);
一个作用域内的每个函数：
extern "C" {
    void foo(int);
    double bar(double);
}
整个头文件（通过包含防护宏）：
#ifdef __cplusplus
extern "C"{
    #endif
    void foo(int);
    double bar(double);

    #ifdef __cplusplus
}
#endif

```
