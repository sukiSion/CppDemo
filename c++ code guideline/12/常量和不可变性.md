# 使用const
**const正确性：意味着使用const来防止const对象被改变**
1、默认情况下，使对象不可变
2、默认情况下，成员函数应声明为const
物理常量性：对象被声明为const，因此不能被改变。它在内存中的表示方式是固定的
逻辑常量性：对象被声明为const，但可以被改变。它的逻辑值是固定的，但它在把内存中的表示方式可能在运行期发生变化（参考mutable.cpp）
**通常当类成员为mutex互斥量时，会被声明为mutable。**
3、默认情况下，传递指向const对象的指针和引用
4、使用const定义构造后值不可变的对象
如需要在线程之间共享一个不可变的变量，只需要将其声明为const即可获得最高的性能
必须以线程安全的方式初始化共享变量
1) 在启动线程前初始化共享变量
2) 使用函数std::call_once与标志std::once_flag
3) 使用具有块作用域的static变量
4) 使用constexpr变量

# 使用constexpr
1、对可以在编译期计算的值使用constexpr
在编译期执行的constexpr函数是纯函数，纯函数由很多优点：
1) 函数调用可以被其结果替换
2) 函数可以在不同的线程上执行
3) 函数调用可以被重排
4) 函数可以很容易地进行单独重构或测试
