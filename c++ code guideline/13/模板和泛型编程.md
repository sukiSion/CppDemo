泛型编程：泛型编程是一种计算机编程风格，在这种风格中，编写算法时可以使用一些以后才能指定的类型，然后再按需实例化时将这些实际类型作为参数指明

# 关于使用
1、使用模板来提高代码的抽象程度
2、使用模板来表达适用于多种参数类型的算法
3、使用模板来表达容器和范围
**容器的是泛型的。多亏了模板，现在可以依赖静态类型系统。**

# 关于接口
1、使用函数对象将操作传递给算法
STL算法的行为通常可以通过一个可调用对象来调整（参考functionObjects.cpp）
**可调用对象：函数、函数对象和lambda表法式**
函数对象的优势：
1) 性能
2) 表法力
3) 状态（参考sumUpFunctionObject.cpp），lambda表法式也可以由状态（参考sumUpLambda.cpp）
2、使用模板别名来简化写法并隐藏实现细节
```cpp
template<typename T>
void user(T& c){
    // ...
    typename container_traits<T>::value_type x; // 不好，过于冗长
    // ...
}
```
等效于
```cpp
template<typename T>
// 给模板起一个别名，后面依旧可以使用泛型的方式来进行使用，比如value_type<T>
using value_type = typename container_traits<T>::value_type x;
void user(T& c){
    // ...
    value_type<T> x;
    // ...
}
```
3、优先使用using而不是typedef来定义别名
原因：
1) 在使用时using最先出现
2) using用起来感觉于auto非常相似
3) using可以很容易地用于模板别名
4、使用函数模板来推导类模板的参数类型（在可行时）
**函数模板可以从其函数参数中推导出其模板参数，从C++17开始，编译期在很多情况下不仅可以从函数参数中推导出模板参数，还可以从构造函数的参数中推导出模板参数（参考templateArgumentDeduction.cpp）**
5、要求模板参数至少为规范或半规范（参考semiRegular.cpp）
半规范类型支持六大操作还必须可交换：
1) 默认构造函数：X()
2) 拷贝构造函数：X(const X&)
3) 拷贝赋值运算符：X& operator = (const X&)
4) 移动构造函数：X(X&&)
5) 移动赋值运算符：X& operator = (X&&)
6) 析构函数：~X()
7) 可交换：swap(X& , X&)
规范：一个相等比较的半规范类型时规范的
1) 等价运算符：operator == (const X& , const X&)
2) 不等运算符：operator != (const X& , const X&)
**STL容器和算法在规范数据类型上运行良好，常用但不规范的类型：引用，它甚至不是半规范类型，因为它不能被默认构造**
6、避免使用有常见名称的高可见度无约束模板（参考argumentDependentLookup.cpp）
实参依赖查找（ADL）：是一组用于查找非限定函数名的规则。非限定函数名称会导致在其参数所在的命名空间中进行额外的查找
非限定名称：指没有作用域运算符（::）的函数。
